# AIGC 视频工具自动化模式 PRD

## 1. 背景与目标

当前视频生产依赖人工串行操作：输入商品 ID、识别商品、选择卖点、生成脚本、配置参数、触发视频生产。该方式适合精细化制作，但在日常批量供给场景下效率较低，人工等待时间长。

自动化模式的目标是把人从“逐步操作者”转为“结果审核者”：运营批量输入商品 ID 后，系统自动完成卖点选择、参数配置、脚本生成、音色选择和视频生产。视频完成后，运营集中审核模型决策结果，对不符合预期的配置进行修改并触发重新生产。后端记录模型原始配置与人工修改之间的差异，用于持续优化模型。

## 2. 用户与场景

- 运营同学：每天需要批量产出大量商品短视频，希望降低重复配置和等待成本。
- 审核同学：关注视频最终效果与配置合理性，需要快速发现并修正脚本、卖点、音色、字幕、BGM 等问题。
- 算法/模型团队：需要采集模型配置与人工修正之间的差距，反向优化自动决策能力。

## 3. 产品定位

在现有人工模式之外新增“自动化模式”。两种模式共用同一套核心生产配置字段和任务体系：

- 人工模式：适合单商品、强人工控制、逐步确认。
- 自动化模式：适合多商品、模型自主决策、人工后置审核。

## 4. 核心流程

1. 运营选择“自动化模式”。
2. 批量输入 N 个商品 ID，支持换行、逗号、空格分隔。
3. 点击“开始自动生成”。
4. 后端模型为每个商品自主完成：
   - 商品识别
   - 卖点选择
   - 参数配置
   - 脚本生成
   - 音色选择
   - 素材选择与视频生产
5. 前端直接在任务列表展示每个商品的自动化生产进度。
6. 视频完成后，运营进入审核：
   - 通过：视频进入可交付状态。
   - 修改配置：编辑卖点、脚本、音色、字幕/BGM/四要素/尾板等。
   - 重新生成：基于人工修改配置触发新任务。
7. 后端记录模型配置、人工修改配置和差异字段。

## 5. 功能需求

### 5.1 模式切换

- 在视频创作页面顶部提供“人工模式 / 自动化模式”切换。
- 默认保留当前人工模式，不改变现有四步流程。
- 切换到自动化模式后，隐藏四步流程，展示批量生产工作台。

### 5.2 批量输入

- 支持一次输入多个商品 ID。
- 支持换行、逗号、空格分隔。
- 前端去重并过滤空值。
- 显示已识别的商品数量。

### 5.3 生产配置

自动化模式只提供与视频产物直接相关的轻量配置：

- 单商品生成数量，支持 1-10 滑动选择
- 字幕
- BGM
- 四要素
- 尾板

AI 模型、内容目标、卖点选择、脚本生成、音色选择等仍由后端模型根据商品、素材与生产策略自动决策。模型决策结果在视频生产完成后暴露给人工审核，审核人可以修改后触发重新生成。

### 5.4 自动配置展示

每个商品任务需展示模型自主选择的配置：

- 商品 ID
- 商品标题
- 商品简称
- 卖点
- 脚本
- 音色
- 视频选项
- 生成状态
- 模型置信度

### 5.5 审核与返工

审核工作台支持：

- 查看视频缩略图和基础信息。
- 查看模型原始配置。
- 编辑审核配置。
- 通过当前视频。
- 基于修改配置重新生成。

重新生成时：

- 原任务保留。
- 新增一条“人工修改后重新生成”的任务记录。
- 记录差异字段，供后续模型优化。

### 5.6 差异记录

系统需记录：

- 模型原始配置。
- 人工最终配置。
- 修改字段。
- 修改时间。
- 审核人。
- 重新生成任务 ID。

## 6. 页面设计

### 6.1 自动化模式触发页

自动化模式页面仅作为任务触发入口，不承载任务详情与审核详情。

- 批量输入商品 ID。
- 配置单商品生成数量和生成选项。
- 点击“开始自动生成”后，直接弹出任务列表。
- 新增任务、生产进度、完成待审核状态均在任务列表中展示。

### 6.2 任务状态

- 自动生产中
- 待审核
- 已通过
- 已返工

## 7. 前端原型范围

本期前端实现仍然保持纯静态 Mock：

- 不接真实后端。
- 用定时器模拟自动生产进度。
- 用 Mock 数据生成商品标题、卖点、脚本、音色与视频缩略图。
- 点击“重新生成”时写入当前任务抽屉，复用现有任务体系。

## 8. 后端接口建议

### 创建自动化批次

`POST /api/automation/batches`

请求：

```json
{
  "productIds": ["6921298477540574538"],
  "generationOptions": {
    "videosPerProduct": 3,
    "enableSubtitles": true,
    "enableBGM": true,
    "enableFlowerText": true,
    "enableEndBoard": true
  }
}
```

### 获取批次状态

`GET /api/automation/batches/{batchId}`

### 提交审核结果

`POST /api/automation/jobs/{jobId}/review`

### 重新生成

`POST /api/automation/jobs/{jobId}/regenerate`

## 9. 成功指标

- 单人每日可处理商品数提升。
- 单商品人工操作时长下降。
- 自动通过率提升。
- 人工修改字段数下降。
- 返工后视频通过率提升。
