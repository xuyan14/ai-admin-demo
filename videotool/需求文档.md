## 1. 产品概述

AIGC 视频工具面向电商/内容运营场景，支持从商品信息到短视频成片的配置、生产、任务管理与剪辑优化。产品提供两种生产范式：

| 模式 | 适用场景 | 核心路径 |
|------|----------|----------|
| **人工模式** | 单商品精细化制作 | 商品识别 → 卖点选择 → 脚本生成 → 参数配置与生产 |
| **批量模式** | 多商品、多脚本批量供给 | 前置配置商品 ID 与脚本 → 一键提交 → 任务列表审核与编辑 |

两种模式共用任务抽屉、视频编辑页、生成选项（字幕 / BGM / 四要素 / 尾板）。

## 2. 用户角色

| 角色 | 职责 |
|------|------|
| 运营 | 配置商品与脚本、提交生产、审核任务结果 |
| 剪辑/运营 | 在编辑页调整文案、音色、BGM、时间轴素材 |
| 产品/研发 | 对接后端生产、脚本、素材与时间轴接口 |

## 3. 功能架构

```
视频创作首页
├── 人工模式（四步流程）
└── 批量模式（商品 + 脚本配置）
         ↓
    任务抽屉（按商品聚合、按脚本展开视频）
         ↓
    视频编辑页（文案 / 音色 / BGM / 时间轴镜头名）
```

## 4. 人工模式需求

### 4.1 流程步骤

1. **商品识别**：输入商品 ID，识别标题、类目、主图等。
2. **卖点选择**：勾选/编辑商品卖点。
3. **脚本生成**：AI 生成口播脚本，支持编辑与裂变。
4. **参数与生产**：配置音色、生成选项，提交视频生产任务。

### 4.2 任务与结果

- 任务进入右侧任务抽屉，展示进度与子任务状态。
- 完成后可预览、编辑视频，进入视频编辑页。

---

## 5. 批量模式需求

### 5.1 模式入口

- 创作页顶部 Tab：**人工模式** / **批量模式**。
- 默认人工模式；切换至批量模式展示商品与脚本配置区。

### 5.2 商品与脚本配置

| 需求项 | 说明 |
|--------|------|
| 商品行 | 每行含：商品 ID、AI脚本生成、删除商品 |
| 默认脚本数 | 新建商品行默认 3 条脚本输入框 |
| 添加脚本 | 按钮位于最后一条脚本下方 |
| 脚本管理 | 可增删脚本；每商品至少保留 1 条 |
| 添加/删除商品 | 支持多商品；至少保留 1 个商品行 |
| 配置提示 | 实时展示商品数、脚本总数 |

**业务规则：**

- 每个商品的生产视频条数 = 该商品下有效脚本文案条数。
- 脚本由运营前置确认；提交后系统完成识别、参数配置与视频生产。

### 5.3 AI 脚本生成

- 按当前脚本输入框数量批量生成文案。
- 未填商品 ID 时不发起生成并提示。
- 每条脚本支持单独「重新生成」。
- 生成过程展示 loading，结果可继续编辑。

### 5.4 Excel 批量导入

| 需求项 | 说明 |
|--------|------|
| 格式 | `.xlsx` / `.xls` |
| 必填列 | 商品ID、脚本（表头兼容 id、productId、script、文案） |
| 合并规则 | 同一商品 ID 多行合并为多条脚本 |
| 模板 | 项目提供 `上传EXCEL.xlsx` 示例 |

### 5.5 生成选项与提交

- 可配置：字幕、BGM、四要素、尾板（默认开启）。
- 提交按钮：「提交并开始生产」。
- 校验：≥1 商品；商品 ID 必填；每商品 ≥1 条有效脚本。
- 提交后打开任务抽屉，展示本批次新建任务。
- 每个商品 1 条任务；任务徽章为「批量模式」；视频卡片数 = 脚本条数。

## 6. 任务列表需求

| 需求项 | 说明 |
|--------|------|
| 模式标识 | 任务标题旁展示「批量模式」或「人工模式」 |

| 视频卡片 | 每条脚本对应一张卡片 |
| 卡片操作 | 完成态支持编辑、预览、保存等 |
| 批次筛选 | 批量提交后抽屉优先展示本批次任务 |

## 7. 视频编辑页需求

### 7.1 页面结构

| 区域 | 内容 |
|------|------|
| 顶栏 | 提交修改、关闭 |
| 左侧「视频优化」 | 脚本文案、音色、口播语速/音量、生成选项 |
| 右侧预览 | 视频播放；字幕、四要素随选项显隐 |
| 底部时间轴 | 视频片段轨道 + 镜头名称 |

### 7.2 脚本文案与音色

- 脚本文案编辑与字数统计。
- 音色 Tab：男性 / 女性 / 中性。
- 口播语速、音量滑条调节。

### 7.3 BGM 与生成选项

- 生成选项：字幕、BGM、四要素、尾板。
- 开启 BGM 时展示「更换BGM」，打开 BGM 库弹窗。
- BGM 库支持筛选、分页、试听；展示当前所选曲名。
- 选项变更联动预览区字幕层、四要素图显隐。

### 7.4 时间轴与镜头名称

| 需求项 | 说明 |
|--------|------|
| 镜头名称展示 | 每个片段缩略图下方展示镜头名称 |
| 默认示例 | 开场介绍、面料质感展示、荷叶领口设计、搭配场景展示 |
| 布局 | 上：缩略图 + 序号；下：镜头名（过长省略） |
| 选中 | 镜头名高亮；提示「已选择：{镜头名称}」 |
| 单击 | 选中片段并切换预览 |
| 双击 | 打开素材库或上传替换 |
| 替换联动 | 替换后同步更新缩略图与镜头名称 |
| 新增片段 | 时间轴「+」追加片段，默认名「镜头{N}」 |

## 8. 数据模型（任务）

```typescript
interface Task {
  id: number;
  title: string;
  productionMode: '批量模式' | '人工模式';
  productId?: string;
  scripts?: string[];
  script: string;
  videoCount: number;
  videos: TaskVideoSlot[];
  status: string;
  automationOptions?: {
    subtitles: boolean;
    bgm: boolean;
    flowerText: boolean;
    endBoard: boolean;
  };
}

interface TaskVideoSlot {
  id: number;
  title: string;
  script: string;
  scriptSource: string;
  status: string;
  thumbnail: string;
}
```

## 9. 接口需求（正式环境）

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/batch/batches` | POST | 创建批量批次（商品 ID + 脚本列表 + 生成选项） |
| `/api/batch/import-excel` | POST | Excel 导入解析（可选，或由前端解析后调 batches） |
| `/api/scripts/generate` | POST | AI 脚本生成（productId、count、regenerateIndex） |
| `/api/videos/{videoId}/timeline` | GET | 获取编辑时间轴（含 lensName） |
| `/api/videos/{videoId}/timeline/segments/{segmentId}` | PUT | 替换片段素材 |
